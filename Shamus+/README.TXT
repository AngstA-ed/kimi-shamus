Shamus+ - New Mazes for Shamus
slx, 2017

Shamus+ is a patch of Shamus allowing to play the extra mazes from the
C64 version. It includes a "Tournament" mode playing all mazes in succession
and a pause function. A rare bug affecting advanced players only is rectified.

This archive contains the following files:

Shamuspl.xex				The patched game executable.
Shamuspl.asm				The assembly source code for the patch program
Shamusplus.asm.pdf			A coloured printout of the assembly source code*
ShamconB.ACT				Action! program converting maze code from C64 to Atari				
New Mazes for Shamus.pdf	A detailed description of the patch and its history and
							the Atari and C64 maze encoding.*
README.TXT					this file
SHAM_C64.MAP				The map data extracted from the C64 version of Shamus.
SHAM_A8.MAP					The map data converted to Atari format.

* only in .zip file for PC, not on ATR.

------------------------------------------------------------------------------------

Instructions:

Use [OPTION] to select the starting Maze. "Tournament" will play through all mazes
in sequence (except the "Original C64" which is almost identical to the original
Atari maze).

When you die in tournament mode the next game will start at the beginning of the 
maze you died in. The maze selection will still read "Tournament". In order to start 
a tournament from scratch, use [OPTION] to rotate through all the mazes until you are
in "Tournament" again.

Use [SPACE] to pause and the fire button to end the pause.
